# Faleshwari Soni — Portfolio Website

A dark, cinematic portfolio website for graphic designer Faleshwari Soni.
Built with plain HTML, CSS and JavaScript. Free to host on GitHub Pages.

## Folder guide

- `index.html` — the page content (text, sections, links)
- `css/` — the design (colors, fonts, layout, animation)
- `js/projects.js` — **the list of portfolio projects (edit this to add work)**
- `js/gallery.js`, `js/script.js` — how the page behaves
- `assets/projects/` — project images
- `assets/images/` — other images (her photo)
- `assets/logo/` — logo files

## How to add a project

1. Save the image in `assets/projects/` (lowercase name, no spaces, e.g. `poster-01.jpg`).
2. Add a block in `js/projects.js` with the title, category, size and image path.
3. Save, then commit and push in GitHub Desktop.
